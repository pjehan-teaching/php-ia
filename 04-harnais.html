Le harnais

Anticiper et détecter

“To harness a coding agent we both anticipate unwanted outputs and try to prevent them, and we put sensors in place […]”

- Birgitta Böckeler, avril 2026

Le harnais est l'ensemble des guides et des capteurs que le développeur construit autour d'un agent pour qu'il produise du code de qualité.

Harness engineering for coding agent users

Guides et capteurs

Guide

Oriente l'agent avant qu'il agisse.

  • spécification
  • AGENTS.md
  • conventions du projet
  • skills

Capteur

Détecte une erreur après l'action, pour que l'agent se corrige.

  • tests
  • formateurs et linters
  • analyse statique
  • revue de code

Un guide réduit les erreurs, un capteur attrape celles qui restent.

Böckeler parle de capteurs computational et inferential. Ce cours s'appuie surtout sur les premiers : rapides, gratuits, fiables.

La boucle avec capteurs

flowchart LR
    P[Prompt] --> M[L'agent modifie le code]
    M --> C["composer check"]
    C --> E{Erreurs ?}
    E -- oui --> M
    E -- non --> F[Tâche terminée]

Sans capteur, l'agent s'arrête quand le code lui semble correct. Avec des capteurs, il s'arrête quand le code passe les vérifications.

Une seule commande

Les capteurs déterministes rapides sont regroupés dans composer check, un script Composer :

  • un seul nom à retenir, pour vous comme pour l'agent
  • un code de retour : 0 si tout passe
  • une sortie concise : l'agent lit chaque ligne, et chaque ligne coûte des tokens

AGENTS.md indique à l'agent de la lancer après chaque modification. Les outils trop lents (Infection) ne tournent qu'en CI.

Un code facile à harnacher

“Not every codebase is equally amenable to harnessing.”

- Birgitta Böckeler
  • des types précis donnent prise à l'analyse statique
  • des couches nettes permettent des règles d'architecture
  • du code découpé se teste

Assainir le fil rouge ne sert pas qu'à le rendre lisible : chaque séance le rend aussi plus vérifiable.

Le développeur reste dans la boucle

Le harnais ne remplace pas la relecture : il la rend moins fréquente et plus ciblée.

  • l'agent fait une erreur
  • vous la corrigez
  • si elle revient : vous ajoutez un guide pour la prévenir, ou un capteur pour la détecter

“A good harness should not necessarily aim to fully eliminate human input […]”

- Birgitta Böckeler
