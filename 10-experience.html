Expérience de référence

Mesurer le harnais

Une expérience répétée compare le travail de l'agent avec et sans harnais :

  • le même prompt d'expérience, versionné dans le dépôt, donné tel quel
  • le même agent, le même modèle
  • deux branches : nu, le code seul, et outille, le code avec le harnais construit pendant le cours

Le résultat est jugé par des tests d'acceptation cachés, écrits par l'enseignant, que l'agent n'a jamais vus.

Deux temps

flowchart LR
    S1["Aujourd'hui : prompt sur nu"] --> H["Séances suivantes : construction du harnais"]
    H --> S6["Dernière séance : même prompt sur nu et sur outille"]
  • aujourd'hui, seule la branche nu existe : c'est le point de référence
  • lors de la dernière séance, la moitié des binômes travaille sur nu, l'autre sur outille, et on agrège les résultats de la classe

Un modèle ne produit jamais deux fois le même résultat : un seul essai ne prouve rien, c'est la série qui compte.

Les règles du jeu

  • le prompt est donné tel quel, sans explication supplémentaire
  • personne n'aide l'agent : on accepte ses actions, on ne corrige pas son code
  • on laisse l'agent aller jusqu'au bout, sans limite d'itérations
  • on observe et on note

On mesure l'agent, pas le développeur qui le pilote.

Exercice - Expérience de référence

40 minutes. L'enseignant donne le prompt à l'agent devant la classe, sur la branche nu.

  1. Lisez le prompt : experiences/01-reaffectation.md. Qu'attendez-vous de l'agent ?
  2. Pendant l'exécution, notez les fichiers lus, les fichiers modifiés et les commandes lancées par l'agent.
  3. Relevez le nombre d'itérations, la durée, et les vérifications que l'agent fait de lui-même.
  4. Relisez le diff : le code vous semble-t-il juste ? Comparez avec les règles de votre inventaire.
  5. Notez le résultat des tests d'acceptation cachés, par groupe de tests.

Dépouillement

  • L'agent a-t-il lu le code qui contenait les règles métier ?
  • A-t-il vérifié son travail ? Avec quoi ?
  • Les erreurs relevées auraient-elles été évitées par une spécification ? Détectées par un outil ? Par un test ?

Le détail des tests cachés reste secret jusqu'à la dernière séance : seul le score est publié.

Gardez vos notes : lors de la dernière séance, on comparera ce résultat à celui de l'agent sur la branche outille.
