Le cours

Objectif

Un agent IA écrit du code vite. Il n'écrit pas forcément du code juste.

Ce cours apprend à construire le harnais qui lui permet de produire du code de qualité :

  • des guides qui l'orientent avant qu'il agisse : spécification, conventions, AGENTS.md
  • des capteurs qui détectent ses erreurs pour qu'il se corrige : formateurs, analyse statique, tests

Les outils de qualité PHP servent aussi bien au développeur qu'à l'agent.

Le fil rouge

helpdesk : une application Symfony de gestion de tickets de support.

  • récente par ses versions : PHP 8.4+, Symfony 8
  • datée par son style : contrôleurs trop gros, peu de types, duplication, aucun test
  • des règles métier que personne n'a écrites ailleurs que dans le code

De séance en séance, vous l'assainissez en ajoutant un outil au harnais.

iia-laval/helpdesk

Une commande pour tout vérifier

Chaque séance ajoute son outil à une seule commande :

composer check

  • vous la lancez avant chaque commit
  • l'agent la lance après chaque modification
  • la CI la lance à chaque push

En fin de cours, elle enchaîne formatage, linters, Rector, PHPStan, Deptrac et tests.

Une expérience pour mesurer

Le cours ne se contente pas d'affirmer que le harnais aide l'agent : vous allez le mesurer.

  • aujourd'hui : un prompt donné à l'agent sur le projet brut
  • dernière séance : le même prompt sur une branche sans harnais et sur une branche avec harnais

Le résultat est jugé par des tests que l'agent n'a jamais vus.

Évaluation

  • Test de positionnement, non noté
  • QCM qualité du code et QCM MCP, en fin de module
  • TP à réaliser à la maison

Test de positionnement

20 minutes pour faire le point sur ce que vous savez déjà :

  • Symfony : contrôleurs, services, Doctrine
  • qualité du code : tests, analyse statique, standards
  • usage des assistants IA

Le résultat n'est pas noté : il sert à adapter le rythme des séances.
