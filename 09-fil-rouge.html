Le fil rouge

helpdesk

Les clients ouvrent des tickets de support, les techniciens les prennent en charge, les commentent et les résolvent.

Symfony 8.1, Doctrine ORM, Twig, base SQLite. Une API JSON et une commande lancée chaque nuit complètent l'interface web.

Exercice - Installer le fil rouge

30 minutes. Prérequis : PHP 8.4 ou plus avec pdo_sqlite, Composer, Symfony CLI (facultatif).

  1. Clonez iia-laval/helpdesk, puis branchez-le sur votre propre dépôt GitHub (slide suivante).
  2. Suivez le README.md : dépendances, migrations, fixtures, serveur.
  3. Ouvrez l'application, choisissez un technicien dans la barre du haut.
  4. Créez un ticket, assignez-le, commentez-le, résolvez-le.
  5. Lancez la commande de fermeture automatique décrite dans le README.md. Que se passe-t-il ?
Installation

Votre dépôt

Votre travail va dans votre dépôt ; celui du cours reste la référence, sous le nom upstream.

git clone https://github.com/iia-laval/helpdesk.git
cd helpdesk
git remote rename origin upstream
git remote add origin git@github.com:<vous>/helpdesk.git
git push -u origin main

Créez le dépôt GitHub vide avant le push. La CI du projet tournera dessus.

Branches et tags

mainvotre travail, séance après séance
nule code d'origine, sans harnais : il ne bouge plus
seance-1, seance-2…tags : l'état attendu au début de chaque séance

En retard sur une séance ? Récupérez les tags et repartez de celui de la séance :

git fetch upstream --tags
git switch -c reprise-seance-3 seance-3

Exercice - Repérer les code smells

45 minutes, en binôme. Lisez le code de src/ et de templates/ et dressez l'inventaire de la dette.

  1. Pour chaque smell repéré, notez le fichier, la ligne et le nom du smell.
  2. Classez-le dans l'une des cinq familles, et notez le principe qu'il enfreint (SOLID, KISS, DRY, PSR).
  3. Notez à part les comportements qui vous semblent faux : ce sont des bugs, pas des smells.
  4. Pour chaque smell, estimez l'outil qui pourrait le détecter, ou s'il faut un test.
  5. Gardez votre inventaire : il servira de liste de contrôle jusqu'à la fin du cours.

Mise en commun

  • Quels smells reviennent dans presque tous les fichiers ?
  • Quelles règles métier avez-vous trouvées ? Où sont-elles écrites ?
  • Lesquelles sont écrites à plusieurs endroits ? Les copies disent-elles la même chose ?
  • Qu'est-ce qu'un nouvel arrivant, humain ou agent, risque de casser en premier ?
